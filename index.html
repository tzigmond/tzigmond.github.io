LOBSTER

Flagship

A high-performance C++20 limit order book that streams live BTC/USD market data from Kraken's WebSocket feed straight into a React dashboard. Built around a lock-free, cache-line-aligned SPSC ring buffer and a flat-array order book — no trees, no locks on the hot path.

Missile Guidance Simulation

Simulation

A 3D simulation of an AIM-120 AMRAAM pursuing an F-16C using proportional navigation guidance. Models boost-phase acceleration to Mach 4, gravity, g-limits, radar-warning-receiver detection, and chained S-turn evasion — rendered as an animated 3D flight path with a live HUD.

03 — Background

About

I'm a computer science student based in Denver, drawn to the parts of software that reward precision — where the difference between a good and a great solution is measured in nanoseconds or in whether an attacker can slip through.

My work spans low-latency systems programming, real-time infrastructure, and security. I like projects that force me to understand a problem all the way down: how a limit order book stays fast under load, how a guidance algorithm converges on a moving target, or how a web app breaks under a crafted request.
