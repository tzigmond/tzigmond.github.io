LOBSTER

Flagship

A trading order book is the structure every exchange uses to match buyers with sellers. This one is built in C++ for raw speed: it streams live Bitcoin prices from Kraken and updates the book in tens of nanoseconds, using a lock-free design that never stalls, then feeds it all to a live web dashboard.

Missile Guidance Simulation

Simulation

A physics simulation of a guided missile intercepting a maneuvering fighter jet, with parameters modeled on published specifications. The missile is based on the AIM-120 AMRAAM and the target on the F-16C Fighting Falcon, with realistic speeds, g-limits, and pilot reaction times. The missile steers using proportional navigation, the same guidance law real interceptors use, while the jet reacts to its radar warning receiver and breaks into hard 9g evasive turns.

Security Lab

Security

A hands-on web security project with two sides. A deliberately vulnerable Flask app carries real flaws (SQL injection, IDOR, broken access control, session forgery) and logs every attack it attracts, paired with a hardened rewrite that fixes each one. A companion notebook then uses Gemini to read the attack logs and score each attempt for risk, so the same project covers building vulnerabilities, defending against them, and analyzing the traffic.

blackhole

Tool

A terminal password-cracking demonstrator with a live interface. It runs brute-force, dictionary, and mask attacks against a target and shows the search space, attempt rate, and progress in real time. Watching a keyspace explode from thousands to trillions as you add characters makes the case for password length better than any lecture.
