LOBSTER

flagship

A high-performance C++20 limit order book that streams live BTC/USD market data from Kraken's WebSocket API straight into a React dashboard. Built around a lock-free, cache-line-aligned SPSC ring buffer and a flat-array order book — no trees, no locks on the hot path.

  • 32ns p50 insert / update / delete
  • 128ns p99.9 tail latency
  • 16ns best bid/ask lookup
  • 2M ops benchmarked, 50-level depth
Network thread (Boost.Beast + simdjson) → Lock-free SPSC queue → Order book engine → FastAPI bridge → React UI

Missile Guidance Sim

A 3D simulation of an AIM-120 AMRAAM pursuing an F-16C using proportional navigation guidance. Models boost-phase acceleration to Mach 4, gravity, g-limits, radar-warning-receiver detection, and chained S-turn evasion — rendered as an animated 3D flight path with a live HUD.

  • Proportional navigation, N = 5
  • 40g missile / 9g airframe limits
  • State machine: FLYING / HIT / MISSED
