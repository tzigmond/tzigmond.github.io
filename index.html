LOBSTER

Flagship

A trading order book — the structure every exchange uses to match buyers with sellers — rebuilt in C++ for raw speed. It streams live Bitcoin prices from Kraken and updates the book in billionths of a second, using a lock-free design that never stalls, then feeds it all to a live web dashboard.

Missile Guidance Simulation

Simulation

A physics simulation of a guided missile chasing a fighter jet. The missile steers using proportional navigation — the same guidance principle real missiles use — while the jet tries to escape with hard evasive turns. The whole pursuit plays out as an animated 3D flight path with a live readout.

03 — Background

About

I'm a computer science student based in Denver, drawn to the parts of software that reward precision — where the difference between a good and a great solution is measured in nanoseconds or in whether an attacker can slip through.

My work spans low-latency systems programming, real-time infrastructure, and security. I like projects that force me to understand a problem all the way down: how a limit order book stays fast under load, how a guidance algorithm converges on a moving target, or how a web app breaks under a crafted request.
